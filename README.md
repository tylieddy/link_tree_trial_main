# link_tree_trial_main
A lightweight, mobile-optimized link-in-bio directory website created as a free alternative to Linktree.
A fully responsive, custom "link-in-bio" profile portal built from scratch. This single-page application acts as a central landing page to neatly present redirection buttons to streaming services, direct download resources, media update portals, and personal contact lines.

## 🚀 Live Demo
You can view the live deployment here:
👉 **[https://github.io](https://github.com/tylieddy/link_tree_trial_main/edit/main)**

## ✨ Features
- 📱 **Mobile-First Design:** Fluid layout perfectly formatted for smartphone screens and web browsers.
- ⚡ **Ultra-Fast Performance:** Constructed using clean, semantic vanilla HTML5 and modern CSS3 without bulky framework overhead.
- 🎨 **Modern Interface:** High-contrast dark mode style featuring clean typography and subtle hover micro-animations.
- 🔗 **Safe Targets:** Ready-to-use directory configuration with customized buttons and visual anchor emojis.
